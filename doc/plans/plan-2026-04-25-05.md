# Plan 19 — `U7` / `U4` newtypes for the MIDI domain (audit P1)

## Context

Audit plan finding **D** (`/Users/cmk/.claude/plans/harmonic-snacking-conway.md`)
identified that `MidiClickConfig`, `MidiClickAccent`, and
`ChannelMode::MidiCc` carry raw `u8` for fields whose actual domain
is the MIDI 7-bit (`0..=127`) or 4-bit (`0..=15`) range. Validation
exists today only as inline `if n > 127 { ... }` blocks in
`crates/core/src/machine/spec.rs`. PR #21's review explicitly
noted "we don't have a `u7` newtype because we don't depend on a
MIDI crate" — but a one-line newtype in core costs nothing and lifts
the validation from runtime parser checks into compile-time
impossibility.

This is **P1** of the audit phasing — the smallest actionable
unit, with no upstream dependencies (P0a/P0b are blocked on
`Conn::then`). It's also a load-bearing prereq for **P3**
(sum-typed `Channel` + per-target role enums): once the role
configs use `U7`/`U4`, the per-target roles can be moved without
also re-doing the field validation story.

User clarification: define the newtypes **locally in agogo-core**,
not in the upstream `connections` crate. `U7` is too MIDI-specific
to belong in a general-purpose Conn library. The Conn impls live
alongside the types in `crates/core/src/midi.rs`.

The conversion logic adapts the Haskell `Cast 'L Int8 Word8` /
`conn` pattern from
`/Users/cmk/Music/Software/Haskell/connections/src/Data/Connection/Word.hs`:

```haskell
conn :: (Bounded a, Integral a, Integral b) => Cast 'L a b
conn = CastL f g
  where
    f = fromIntegral . max 0           -- a → b: clamp negatives
    g = fromIntegral . min (f maxBound) -- b → a: clamp to a's max
```

Translated to Rust for `U7 ↔ u8` (the source type is unsigned, so
`max 0` is a no-op):
- `ceil:  U7 → u8` = `u7.0` (exact embed; no negatives possible)
- `inner: u8 → U7` = `U7(min(x, 127))` (saturating)

That's `Conn::new_left(ceil, inner)`. Same shape for `U4 ↔ u8`
with the bound set to 15.

## Goal

1. Define `U7(u8)` (`0..=127`) and `U4(u8)` (`0..=15`) newtypes in
   a new `crates/core/src/midi.rs` module.
2. Provide checked constructors (`U7::new`, `U4::new`) returning
   `Option<Self>`.
3. Provide saturating Galois connections `U7U8: Conn<U7, u8>` and
   `U4U8: Conn<U4, u8>` adapted from the Haskell `conn` pattern.
4. Migrate `MidiClickConfig`, `MidiClickAccent`, and
   `ChannelMode::MidiCc` to use `U7` / `U4` instead of raw `u8`.
5. Collapse the parser's inline `if n > 127` / `if !(1..=16)`
   blocks into one-line `U7::new(n).ok_or(...)` /
   `U4::new(n-1).ok_or(...)` calls.

## Dependency Graph

```
T1 (define U7, U4 + Conn<U7,u8>, Conn<U4,u8> + props) ──┐
                                                        ├─→ T3 (parser migration)
T2 (migrate MidiClickConfig + MidiCc field types) ─────┘     │
                                                              ├─→ T5 (Display + smoke)

```

## Tasks

### T1 — `crates/core/src/midi.rs` (NEW module)

```rust
//! MIDI domain newtypes.
//!
//! `U7` (0..=127) covers note numbers, velocities, CC values, and
//! channel-pressure values. `U4` (0..=15) covers MIDI channel
//! numbers (zero-based; user-facing 1..=16 is mapped at the spec
//! parser).
//!
//! These types are **MIDI-specific** by design — they do not
//! belong in the general-purpose `connections` crate. The Conn
//! impls below adapt the Haskell `Cast 'L a b` saturating pattern
//! from `Data.Connection.Word`.

use connections::conn::Conn;
use connections::lattice::Ple;

#[repr(transparent)]
#[derive(Copy, Clone, Debug, PartialEq, Eq, PartialOrd, Ord, Hash, Default)]
pub struct U7(pub u8);

impl U7 {
    pub const MAX: u8 = 127;
    pub const ZERO: Self = Self(0);

    /// Returns `Some(U7(x))` iff `x <= 127`.
    pub const fn new(x: u8) -> Option<Self> {
        if x <= Self::MAX { Some(Self(x)) } else { None }
    }
}

impl Ple for U7 {
    fn ple(&self, other: &Self) -> bool { self.0 <= other.0 }
}

impl From<U7> for u8 {
    fn from(x: U7) -> u8 { x.0 }
}

impl core::fmt::Display for U7 {
    fn fmt(&self, f: &mut core::fmt::Formatter<'_>) -> core::fmt::Result {
        self.0.fmt(f)
    }
}

// ── U4 — same shape, MAX = 15. ──

#[repr(transparent)]
#[derive(Copy, Clone, Debug, PartialEq, Eq, PartialOrd, Ord, Hash, Default)]
pub struct U4(pub u8);

impl U4 {
    pub const MAX: u8 = 15;
    pub const ZERO: Self = Self(0);

    pub const fn new(x: u8) -> Option<Self> {
        if x <= Self::MAX { Some(Self(x)) } else { None }
    }
}

impl Ple for U4 {
    fn ple(&self, other: &Self) -> bool { self.0 <= other.0 }
}

impl From<U4> for u8 {
    fn from(x: U4) -> u8 { x.0 }
}

impl core::fmt::Display for U4 {
    fn fmt(&self, f: &mut core::fmt::Formatter<'_>) -> core::fmt::Result {
        self.0.fmt(f)
    }
}

// ── Saturating Galois connections (Haskell `Cast 'L`). ──
//
// For each type, `ceil: T → u8` is the exact embedding (no
// rounding needed; T's domain is a subset of u8's), and
// `inner: u8 → T` saturates to `T::MAX`. `Conn::new_left` sets
// `floor = ceil`, matching the Haskell one-sided-adjoint shape.

pub const U7U8: Conn<U7, u8> = {
    fn ceil(x: U7) -> u8 { x.0 }
    fn inner(x: u8) -> U7 {
        U7(if x <= U7::MAX { x } else { U7::MAX })
    }
    Conn::new_left(ceil, inner)
};

pub const U4U8: Conn<U4, u8> = {
    fn ceil(x: U4) -> u8 { x.0 }
    fn inner(x: u8) -> U4 {
        U4(if x <= U4::MAX { x } else { U4::MAX })
    }
    Conn::new_left(ceil, inner)
};
```

### T3 — parser migration (`crates/core/src/machine/spec.rs`)

Today's parser has inline range checks at four sites:
- `note` (line 173-178): `if n > 127`
- `vel` (line 185-190): `if n == 0 || n > 127` — keep the `n == 0`
  reject (vel=0 = Note Off), but lift the upper bound into `U7::new`.
- `mch` (line 197-203): `if !(1..=16).contains(&n)` — split into
  "must be 1..=16" + `U4::new(n-1)`.
- `accent-note` (line 221-226): `if n > 127`
- `accent-vel` (line 233-238): `if n == 0 || n > 127`

Pattern becomes:

```rust
"note" => {
    let raw = v.parse::<u8>().map_err(|e| BadValue("note", e.to_string()))?;
    note = Some(U7::new(raw).ok_or_else(||
        BadValue("note", format!("must be 0..=127, got {raw}"))
    )?);
}
```

Storage types in the parser also change:
- `let mut note: Option<U7> = None;` (was `Option<u8>`)
- Same for `vel`, `accent_note`, `accent_vel`.
- `let mut mch: Option<U4> = None;` (was `Option<u8>` for the
  zero-based channel; the user-facing 1..=16 → 0..=15 subtraction
  happens at parse, then `U4::new` validates).

### T4 — renderer migration (`crates/core/src/out/midi.rs`)

`render_midi_click_block` constructs MIDI bytes by OR-ing the
channel nibble into the status byte:

```rust
// Today
sink.send_at(&[MIDI_NOTE_ON | cfg.ch, n, v], ev.sample_index);
//                            ^^^^^^ raw u8

// After (cfg.ch: U4)
sink.send_at(&[MIDI_NOTE_ON | cfg.ch.0, n.0, v.0], ev.sample_index);
//                            ^^^^^^^^ ^^^ ^^^ U4/U7 → u8 via .0
```

Same shape inside the `match cfg.accent { Some(a) ... }` arm:
the byte construction extracts `.0` from each `U7` / `U4`.

The `click_cfg` test helper at `out/midi.rs:528-535` updates its
parameter types from `(u8, u8, u8, ...)` to `(U7, U7, U4, ...)`.
