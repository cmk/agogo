# Plan 01 — `time/`: port the Cirklon grid-and-tick algebra

## Goal

Deliver `agogo-core::time` as a complete, property-tested Rust port of
the Haskell Cirklon `Control.Cirklon.Type.Time` module. Pure logic
only — no I/O, no platform code, no audio, no tempo. Tempo/sample-rate
coupling is deliberately deferred to a later integration sprint.

## Context

`doc/agogo.md` §§2, 6, 7 explain why the grid algebra sits in its own
layer: scheduling happens in `Tick` space, `Tick ↔ Time` conversions
are tempo-independent Galois connections, and `Tick → Samples` only
happens at the audio boundary. This sprint delivers that layer. It is
parallel-independent of `plan-2026-04-22-02` (sync/ — peak detector +
PLL): the two plans touch disjoint modules.

The source of truth is the Haskell module in the sibling `recologic`
repo (under `Software/Haskell/recologic/client/`), ~822 lines, ~45
exported defs: distributive biheyting lattice on TBase, five Galois
connections, swing, and three envelopes. Read that file alongside
this plan during implementation.

The `connections` crate lives at sibling path `../connections` (one
level up from this repo's root). Its `Conn<A, B>` uses bare `fn`
pointers — no closure capture — which is exactly right for the
tempo-independent connections this sprint needs. Verified:
`connections/src/conn.rs:9-13`.

## Tasks

### T0 — Workspace deps and module scaffold

- Add `connections = { path = "../connections" }` to
  `[workspace.dependencies]` in the root `Cargo.toml`, and pull it
  into `crates/core/Cargo.toml` under `[dependencies]`.
- Add `proptest = { workspace = true }` under `[dev-dependencies]` of
  `crates/core/Cargo.toml` (workspace dep already exists).
- Create `crates/core/src/time.rs` as the module root (modern layout
  per the repo convention — no `mod.rs`). Declare empty submodules
  `tbase`, `tick`, `conn`, `swing`, `envelope`. Re-export the public
  surface from `crates/core/src/lib.rs`.

### T1 — TBase enum + divisibility preorder

`crates/core/src/time/tbase.rs`.

- `enum TBase` with 14 constructors matching the Haskell source:
  `T1, T2, T4, T8, T16, T32, T64, T128` (straight), `T4d, T8d, T16d,
  T32d` (dotted), `T4t, T8t, T16t, T32t, T64t, T128t` (triplets).
  Adjust final count to match the Haskell; pick the exact set from
  the source file during implementation.
- Each variant has a `tick_count()` returning its size in 192-PPQN
  ticks (e.g. `T4 = 192`, `T8 = 96`, `T16 = 48`, `T8t = 64`).
- `impl Ple for TBase` — divisibility preorder: `a.ple(b)` iff
  `a.tick_count()` divides `b.tick_count()`.

### T2 — Lattice operations

Still in `time/tbase.rs`.

- `fn join(a: TBase, b: TBase) -> TBase` — LCM of tick counts,
  resolved back to a TBase constructor. The lattice is **closed** on
  the 14 constructors by construction (verify with an exhaustive test).
- `fn meet(a: TBase, b: TBase) -> TBase` — GCD, same shape.
- `fn heyting(a: TBase, b: TBase) -> TBase` — implication `a // b`:
  coarsest `c` such that `a ∧ c ≤ b`.
- `fn coheyting(a: TBase, b: TBase) -> TBase` — co-implication `a \\ b`.
- `fn neg(x)`, `fn non(x)`, `fn boundary(x)`.

### T3 — Galois connections

`crates/core/src/time/conn.rs`.

Five connections, all as `Conn<A, B>` values from the `connections`
crate (bare `fn` pointers, tempo-independent):

1. `quantize_at(tb: TBase) -> Conn<Tick, Time>` — rounds a tick count
   to nearest `Time` on a chosen grid. The `tb` parameter is a
   compile-time dispatch via per-variant constants (one `Conn` per
   `TBase` variant), since `fn` pointers cannot close over `tb`.
2. `ticks() -> Conn<Tick, Time>` — the master `Tick ↔ Time`
   connection.
3. `rat_tick() -> Conn<Rational, Tick>` — rational whole-note
   durations. Use `num-rational` (add as a dep if not present).
4. `time() -> Conn<(Time, Time), Time>` — divisibility lattice on
   pairs (join/meet via LCM/GCD on tick counts).
5. `tbase() -> Conn<(TBase, TBase), TBase>` — the divisibility
   lattice connection on TBase.

For the `quantize_at` per-variant dispatch: provide a const table
`pub const QUANTIZE: [Conn<Tick, Time>; 14]` indexed by `TBase as
usize`, or a `fn quantize_at(tb: TBase) -> &'static Conn<Tick, Time>`
matching on the variant. Pick whichever clippy is happy with.

### T4 — Tick and Time types

`crates/core/src/time/tick.rs`.

- `#[repr(transparent)] pub struct Tick(pub u32);` with 192 PPQN as a
  module-level `const PPQN: u32 = 192;` constant.
- `pub struct Time { pub beats: u32, pub base: TBase }`.
- `fn time_to_tick(t: Time) -> Tick` and `fn from_ticks(n: Tick) ->
  Time` (canonical form: coarsest base, smallest beat count, per the
  Haskell).

### T5 — Swing and alignment

`crates/core/src/time/swing.rs`.

- `pub struct SwingConfig { pub amount: i32, pub multiplier: i32 }`
  (match the Haskell — integer-valued, not float, to avoid FP drift in
  property tests).
- `fn effective_tick(cfg: &SwingConfig, t: Tick) -> Tick` — applies
  swing to off-beat 16th-note positions; pass-through otherwise.
- `fn is_swung_step(cfg: &SwingConfig, t: Tick) -> bool`.
- `fn is_aligned(t: Tick, base: TBase) -> bool`.

### T6 — Envelopes

`crates/core/src/time/envelope.rs`.

- `fn opening(t: Tick, n: Tick) -> u8` — linear 0→255 over `[0, n]`.
- `fn closing(t: Tick, n: Tick) -> u8` — linear 255→0.
- `fn s_curve(t: Tick, n: Tick) -> u8` — Hermite smoothstep,
  monotonic 0→255.

All clamp at the endpoints (saturating, not wrapping).

### T7 — CLI `time schedule` subcommand

Extend `crates/cli/src/main.rs` with a `time schedule` subcommand
using `clap` (add as a dep; confirm nothing simpler in use already).
Flags: `--bpm <f32>` (informational only — not used in Tick space),
`--tbase <TBase>`, `--swing <f32>` (converted to SwingConfig by a
helper), `--bars <u32>`. Output one tick offset per line for the
resulting schedule. Pure compute; no audio.

### T8 — Proptest strategies

Extend `crates/core/src/arb.rs`:

- `fn arb_tbase() -> impl Strategy<Value = TBase>`
- `fn arb_tick() -> impl Strategy<Value = Tick>`
- `fn arb_time() -> impl Strategy<Value = Time>`
- `fn arb_swing() -> impl Strategy<Value = SwingConfig>` — bias toward
  boundary values (amount = 0, amount = max, multiplier = 1).

Use `prop_oneof!` with frequency weights per the repo convention.

## Verification

### Properties (must pass)

| Property | Module | Invariant |
|----------|--------|-----------|
| `tbase_lattice_absorption` | `time::tbase` | `a ∧ (a ∨ b) = a` and `a ∨ (a ∧ b) = a` |
| `tbase_lattice_distributivity` | `time::tbase` | `a ∧ (b ∨ c) = (a ∧ b) ∨ (a ∧ c)` |
| `tbase_heyting_adjunction` | `time::tbase` | `a ∧ c ≤ b ⟺ c ≤ a // b` |
| `tbase_join_is_lcm` | `time::tbase` | tick-count of `a ∨ b` = LCM of individual tick counts |
| `tbase_meet_is_gcd` | `time::tbase` | tick-count of `a ∧ b` = GCD of individual tick counts |
| `quantize_at_galois` | `time::conn` | `floor(x) ≤ x ≤ ceil(x)` and `inner ∘ floor = inner ∘ ceil = id` on grid-aligned ticks |
| `ticks_round_trip` | `time::conn` | for grid-aligned ticks, `inner(floor(t)) = t` |
| `rat_tick_monotone` | `time::conn` | `a ≤ b` in `Rational` ⟹ `floor(a) ≤ floor(b)` in `Tick` |
| `swing_zero_mean_over_beat` | `time::swing` | sum of `effective_tick(t) - t` across one beat = 0 for every `SwingConfig` |
| `swing_is_aligned_invariant` | `time::swing` | `is_aligned(effective_tick(t), base) = is_aligned(t, base)` on aligned steps |
| `envelope_endpoint` | `time::envelope` | `opening(0,n)=0`, `opening(n,n)=255`; dual for `closing`; both endpoints for `s_curve` |
| `s_curve_monotone` | `time::envelope` | strictly non-decreasing on `[0, n]` |

### Spot checks

- `T4.tick_count() == 192`, `T8t.tick_count() == 64`, `T16.tick_count() == 48`.
- `join(T4, T8t) == T8t` (since 192 and 64: LCM = 192 → T4 — actually
  verify during implementation; document the real answer).
- `from_ticks(Tick(48)) == Time { beats: 1, base: T16 }` (canonical form).
- `opening(Tick(5), Tick(10)) == 127` or `128` (document expected
  rounding).
