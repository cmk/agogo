# CLI Crate Cleanup

## Summary

Restructure `agogo-cli` around command modules, with trace code under
`trace/`, while preserving the existing CLI surface and CSV output.
Also fix the confirmed feature-gating debt where `--no-default-features`
combinations compile core-dependent code without enabling `agogo-core`.

## Key Changes

- Move trace implementations under `cli/src/trace/`:
  `midi_trace.rs` -> `trace/midi.rs`, `channel_trace.rs` ->
  `trace/channel.rs`, and `sync_trace.rs` -> `trace/sync.rs`.
- Add shared trace helpers for audio sample-rate validation,
  straight `ChannelCommon` construction, and trace range overflow checks.
- Split CLI parser and command structure out of `main.rs`; keep
  `main.rs` as the thin binary entrypoint.
- Rename non-trace helpers for consistency:
  `time_sched.rs` -> `time/schedule.rs`, `link_probe.rs` ->
  `link/probe.rs`, and `link_commands.rs` -> `link/commands.rs`.
- Fix `cli` feature dependencies so `link`, `demo`, and `run` compile
  with their required `core` dependency.
- Update moved-file references in `scripts/check-floats.sh`,
  `CLAUDE.md`, and local docs/comments.

## Test Plan

- `cargo test -p agogo-cli --no-run`
- `cargo test -p agogo-cli --no-default-features --no-run`
- `cargo test -p agogo-cli --no-default-features --features core --no-run`
- `cargo test -p agogo-cli --no-default-features --features link --no-run`
- `cargo test -p agogo-cli --no-default-features --features demo --no-run`
- `cargo test -p agogo-cli`
- `cargo fmt --check`
- `scripts/check-floats.sh`

## Review

- `cli/src/main.rs` / `cli/src/trace/midi.rs` /
  `cli/src/time/schedule.rs` — feature-gate bug: core-dependent parser
  types and modules compile without `agogo-core` under
  `--no-default-features`.
- `cli/src/trace/channel.rs` + `cli/src/trace/midi.rs` — duplicated
  sample-rate allowlist, `ChannelCommon` setup, and overflow preflight;
  consolidate under `trace/`.
- `cli/src/link/probe.rs` test — existing environment-sensitive
  `peers == 0` assertion can fail on a LAN with real Link peers; keep
  behavior unchanged unless implementing this cleanup exposes the test,
  then relax only the peer-count assertion.

## Assumptions

- No other agent instances are currently working in this repo.
- This is a structural cleanup: command names, flags, output headers,
  CSV row formats, and exit behavior stay unchanged.
