# Plan 25 — Q1b: Workspace rename to canonical FD / S0xx names

## Goal

Drop the transitional aliases that Q1a (PR #29) put in place and
migrate every workspace call site to the canonical 4-character
names from the vendored `time::decimal` and `time::sample` modules.
Two intentional **domain aliases** survive at the `agogo_core::fxp`
re-export layer (`Micro = FD06`, `Pico = FD12`) — these read as
time-unit words at the FFI seams and the call-site overhead of
spelling out `FD06`/`FD12` there is genuinely worse than the
alias.

This is step Q1b of the four-PR Conn-discipline + float-surface
sweep. Pure mechanical refactor: zero behaviour change, all
existing tests pass identically.

## Context

Q1a stood up the new types under canonical names
(`FD00..FD12`, `S044..S192`, `F064FD??`, `FD12FD??`, `FD12Sxxx`)
plus a transitional alias module so every existing call site
kept compiling. Q1b is the mechanical sweep that drops the
transitional aliases and updates the call sites.

## Review

### Implementation deviations from the plan

- **`Nano` was dropped instead of kept as a KEEP.** The original
  meta-plan listed Nano as one of three intentional FFI-seam
  aliases. The Q1b sweep audit found zero callers for `Nano` in
  agogo's codebase — `sync::pll` uses `Pico` for jitter math,
  not `Nano`. Without callers, the KEEP rationale ("domain word
  at FFI seams") doesn't apply, so Nano joins the
  Uni/Deci/Centi/Milli batch of dropped-because-unused aliases.
  The two surviving KEEPs are `Micro` and `Pico` (both with
  20+ and 10+ call sites respectively).

- **`fxp.rs` module docstring rewritten.** The previous docstring
  referenced `Uni / Deci / Centi / Milli` and pointed at
  `connections` as the source of the ladder. After Q1a vendoring
  + Q1b rename, neither claim is accurate — the docstring now
  documents the canonical names + the two KEEP aliases, and
  points at the agogo-local `crate::time::{decimal, sample}`
  modules.

- **`time/decimal.rs` module docstring** had inline parentheticals
  like `(Uni, 1 s)` annotating each FD rung. Stripped the alias
  word, kept the time-unit annotation. The module now reads
  cleanly as a self-contained decimal-SI ladder doc.

### `#[ignore]`d properties

None added. The two existing `#[ignore]`s
(`time::swing::tests::swing_is_bar_periodic` and one other)
predate this PR.
