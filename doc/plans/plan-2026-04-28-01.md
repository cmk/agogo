### T2 — Fix test import paths

The `property` module was renamed to `prop` and its `laws` submodule was
split into `prop::conn` (Galois-connection predicates) and `prop::lattice`
(Heyting/Coheyting predicates). All five test import sites use Conn-law
predicates and map to `prop::conn`. We alias it `as laws` to keep every
`laws::conn_*` call site unchanged (the predicate call sites had already
been updated from `cast_*` to `conn_*` in a prior sprint).

**`crates/core/src/time/decimal.rs`**
- `connections::property::arb::extended_float_f64` → `connections::prop::arb::extended_float_f64`
- `connections::property::laws` → `connections::prop::conn as laws` (×2)

**`crates/core/src/time/sample.rs`**
- `connections::property::laws` → `connections::prop::conn as laws` (×2)

### T3 — Rename non-conformant local Conn constants

Grep audit of all `pub const … : Conn<` declarations found two names in
`crates/core/src/midi.rs` shorter than 8 chars:

| Old name | New name | Type |
|----------|----------|------|
| `U7U8`   | `U007U008` | `Conn<U7, u8>` |
| `U4U8`   | `U004U008` | `Conn<U4, u8>` |

`U007` codes the `U7` MIDI newtype (unsigned, 7-bit saturating range) under
the A123 form; `U004` codes `U4` (4-bit). `U008` codes `u8`. All usages
are internal to `midi.rs`.
