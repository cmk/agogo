# plan-2026-05-07-01.md - Template workflow port

## Goal
Port the current `template-rust` workflow contract into `agogo` while preserving `agogo`-specific checks, audit coverage, and repository rules.

## Dependency Graph

```
T1 -> T2 -> T4 -> T5
T1 -> T3 -> T4
```

## Tasks

### T1 - Rename workflow scripts to the current contract

- Problem or motivation: `agogo` still uses the older `local_review.sh`, `safe_merge.sh`, `autosquash.sh`, `review_path.sh`, `extract_pr_body.sh`, `pull_reviews.py`, and `reply_review.py` names.
- Solution / implementation approach: replace those entrypoints with the current `pr_*`, `git_*`, and shared GitHub helper scripts from `template-rust`.
- Types or API surface: shell and Python workflow scripts under `scripts/`.

### T2 - Preserve `agogo`-specific gates

- Problem or motivation: a blind copy of template hooks would drop `agogo`-specific checks for floats, connections, boundary panics, and layers.
- Solution / implementation approach: keep those product gates, update script names to underscore style where appropriate, and retain the current layer DAG configuration.
- Types or API surface: `.githooks/`, `scripts/check_layers.sh`, `scripts/check_pii.sh`, and existing `agogo` check scripts.

### T3 - Keep the audit harness active

- Problem or motivation: `agogo` already has `doc/audits`, so the template audit runner is useful here rather than dormant.
- Solution / implementation approach: port the current audit runner/report wrapper and Python tests while preserving `agogo` audit definitions.
- Types or API surface: `scripts/audit_run.py`, `scripts/audit_report.sh`, `tests/test_audit_run.py`.

### T4 - Update docs and command playbooks

- Problem or motivation: `AGENTS.md`, `doc/workflow.md`, `.claude/commands`, `.gitignore`, and workflow prose refer to old script names and `.watch-pr`.
- Solution / implementation approach: update workflow-sensitive documentation and command playbooks to the current `pr_*` / `.pr-watch` contract.
- Types or API surface: repo docs and Claude command markdown files.

### T5 - Verify the workflow port

- Problem or motivation: this is infrastructure, so regressions show up as broken scripts or stale gates rather than Rust API failures.
- Solution / implementation approach: run shell syntax checks, Python unittest discovery, PII/layer checks, and lightweight workflow-state probes before final review.
- Types or API surface: local test commands only.
