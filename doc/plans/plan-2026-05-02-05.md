# Plan 2026-05-02-05 — Split transport playhead module

## Goal

Move the transport runtime out of `control.rs` into
`control::transport`, rename `Machine` to `Playhead`, and update
code plus docs to use the new runtime name.

## Dependency Graph

```
T1 module split + re-export
    |
    v
T2 Playhead rename
    |
    v
T3 docs/reference repair
    |
    v
T4 verification + workflow docs
```

## Tasks

### T1 — `control::transport` module split

**Problem.** `crates/core/src/control.rs` currently mixes the control
facade, event/sync submodule exports, transport policy, stop-handle
state, the N-channel runtime, and runtime tests in one file.

**Solution.** Add `crates/core/src/control/transport.rs` with the
`control` layer header and move the runtime implementation, transport
policy/state, stop handle, and related tests into it. Keep
`control.rs` as the facade that declares `event`, `sync`, and
`transport`.

**Types or API surface.** `control::transport` becomes the implementation
home for the transport runtime types. `control.rs` re-exports the public
runtime types so callers can keep importing from `agogo::core::control`.

### T2 — `Machine` to `Playhead`

**Problem.** The runtime is named `Machine`, but the requested public
name is `Playhead`.

**Solution.** Rename `Machine<R>` to `Playhead<R>` and
`MachineStopHandle` to `PlayheadStopHandle` across code, tests,
rustdoc links, panic strings, and comments. Preserve behavior.

**Types or API surface.**

- `Playhead<R>` replaces `Machine<R>`.
- `PlayheadStopHandle` replaces `MachineStopHandle`.
- `TransportPolicy` and `TransportState` keep their names.
- No deprecated `Machine` alias is provided; this is a hard rename.

### T3 — docs/reference repair

**Problem.** Historical docs and notes refer to the old runtime name and
some path references point at stale `machine.rs` or `control::Machine`
locations.

**Solution.** Update tracked docs under `doc/` and the explicitly
requested `doc/notes/` notes so runtime/API references say `Playhead`
and paths point at `control.rs` or `control/transport.rs` as
appropriate. Do not rewrite unrelated terms such as "MIDI Machine
Control" or generic "state machine" prose.

**Types or API surface.** Documentation only.

### T4 — verification + workflow docs

**Problem.** A structural rename can compile while still leaving stale
docs or public-path references behind.

**Solution.** Run the normal repo gates and targeted stale-reference
scans. Finalize this plan and the PR review artifact after the code and
docs are green.

**Types or API surface.** No additional API changes.
