# Plan 13 — `host-cpal` + `host-midi`: RT audio callback plumbing

## Goal

Close v0.1 output-chain slot 2 of 3. Wire the audio-input → PLL →
tick-schedule → MIDI-clock pipeline onto real platform back-ends
(cpal for audio input, midir for MIDI output) through a lock-free
control plane (rtrb SPSC). Ships an `agogo demo` CLI that proves the
end-to-end path against real hardware. Plan 14 then adds the
N-channel `Playhead` struct and polishes `agogo demo` → `agogo run` +
`bin/agogo`.

## Context

`doc/versions/version-0.1.md` lists this slot:

> `host/cpal` + `host/midir` + `rt/` — cross-platform audio input via
> cpal, MIDI output via midir. The audio callback hot loop and
> `rtrb`-based control plane.

`doc/agogo.md` §3 groups these under a single `src/host/` directory;
in the agogo workspace the pattern is already **one platform
back-end per sibling crate** (see `crates/host-link`). Plan 13
splits the slot's two back-ends into two crates on that pattern:

- **`crates/host-cpal`** — audio input via cpal + the RT callback +
  the control-plane SPSC. Self-contained.
- **`crates/host-midi`** — `MidiSink` impl backed by midir.
  Self-contained; nothing references `cpal`.

The two crates talk only through the `agogo-core` trait surface:
Plan 12's `MidiSink` (already merged) and this plan's new
`agogo_core::host::AudioHost`. They can ship as one PR (simplest) or
two (if review load demands — the midir crate is ~80 lines, cpal+rt
is the bulk). Noted in §MR split below.

§4 of agogo.md pins the precision expectation: midir is the
cross-platform MIDI baseline with **~1 ms USB-bus-limited jitter**;
platform-native sinks (CoreMIDI, JACK, WinMM) are post-v0.5
upgrades. Plan 13 inherits midir's precision — it is not the
precision work.

Prerequisite: **Plan 12** (`out/midi`) must be merged. Both new
crates consume `MidiSink`, `TestSink`, `render_channel_block`, and
`MidiRtByte` from `agogo_core::out::midi`.

Not prerequisites but reference points:
- `PhaseSource<R: SampleTime>` in `sync/source.rs` is
  compile-time-rate-parameterised. Plan 13 dispatches the rate at the
  CLI boundary (following the existing `agogo sync trace --sr`
  pattern); the callback is monomorphised per rate.
- Plan 09 (`LinkSession`) in flight: Plan 13 does not depend on
  Link. `PhaseSource::Custom` already accepts a boxed Link source if
  the user runs with `--source=link`; Plan 13 wires only `Internal`
  and `External` and leaves a clean integration seam.

## Core additions (`agogo-core`)

### `agogo_core::host` — new module

Parallels `agogo_core::out::midi` from Plan 12. Owns the trait surface
that any audio-host back-end implements.

```rust
// crates/core/src/host.rs (new file, wired via `pub mod host;` in lib.rs)

/// Cross-platform audio-host trait. Concrete back-ends (cpal, and
/// future JACK / CoreAudio) live in sibling crates and implement
/// this trait. Mirrors the `MidiSink` / `MidirSink` split from
/// Plan 12 — core holds the contract, platform crates hold the
/// implementations.
pub trait AudioHost {
    fn run(
        self,
        cfg: Config,
        cb: Box<dyn FnMut(&mut AudioIo) + Send>,
    ) -> Result<Handle, AudioHostError>;
}

/// `#[non_exhaustive]` so v0.5's Link work can add a cpal
/// `timestamp().playback` field without breaking downstream
/// pattern matches (`link.md:23-29` — Link queries need the
/// "first-sample-hits-DAC" instant, not `now()`).
#[non_exhaustive]
pub struct AudioIo<'a> {
    pub input: &'a [f32],
    pub output: &'a mut [f32],
    pub buffer_start_sample: u64,
    pub sample_rate: u32,
    pub frames: usize,
}

pub struct Config {
    pub input_device: Option<String>,
    pub output_device: Option<String>,
    pub sample_rate: u32,
    pub buffer_frames: u32,
    pub input_channels: u16,
    pub output_channels: u16,
}

/// Opaque stream handle. Back-ends box a platform-owned stream
/// object inside; dropping the handle tears the stream down.
pub struct Handle { /* platform-specific payload behind a trait obj */ }

#[derive(Debug, thiserror::Error)]
pub enum AudioHostError {
    #[error("no default input device")]       NoInputDevice,
    #[error("device not found: {0}")]         DeviceNotFound(String),
    #[error("unsupported sample rate: {0}")]  UnsupportedSampleRate(u32),
    #[error("back-end: {0}")]                 Backend(Box<dyn std::error::Error + Send + Sync>),
}
```

`lib.rs` gains `pub mod host;` next to the existing modules. No
dependency on cpal — just `thiserror` (already a core dep).

### `agogo_core::channel::scheduler::tick_stream_into`

Alloc-free sibling of `tick_stream`. Writes into a caller-owned
`Vec<ScheduledEvent>`. Used by the RT callback so the hot loop never
touches the heap.

```rust
pub fn tick_stream_into(
    buf: &mut Vec<ScheduledEvent>,
    channel: &Channel,
    stc: &SampleTickConn,
    buffer_start_sample: u64,
    frames: usize,
);
```

Same logic as the existing `tick_stream`; `tick_stream` becomes a
thin wrapper that `Vec::new()`s then delegates, preserving its
public surface unchanged.

}

impl CpalHost {

    pub fn with_input_name(name: &str) -> Result<Self, AudioHostError>;

```rust
pub struct MidirSink {
    conn: std::sync::Mutex<::midir::MidiOutputConnection>,
    port_name: String,
}

impl MidirSink {
    pub fn open(port_name: &str) -> Result<Self, MidirSinkError>;
    pub fn list_output_ports() -> Result<Vec<String>, MidirSinkError>;
}

impl agogo_core::out::midi::MidiSink for MidirSink {
    /// Forwards `msg` to the underlying `MidiOutputConnection`
    /// **immediately** — midir has no native scheduler, so
    /// `at_sample` is metadata only. Dispatch jitter inherits
    /// midir's ~1 ms USB-bus-limited figure (agogo.md §4).
    /// Precision upgrades land with platform-native sinks
    /// post-v0.5.
    fn send_at(&self, msg: &[u8], _at_sample: u64) {
        if let Ok(mut conn) = self.conn.lock() {
            if let Err(e) = conn.send(msg) {
                tracing::warn!(?e, "midir send failed");
            }
        }
    }
}

#[derive(Debug, thiserror::Error)]
pub enum MidirSinkError {
    #[error("midir init: {0}")]            Init(String),
    #[error("no MIDI output port: {0}")]   PortNotFound(String),
    #[error("connect: {0}")]               Connect(String),
}
```

Interior `Mutex` because `MidiOutputConnection: !Sync`. The lock is
only acquired on the control-plane drain thread (T3), never the
audio thread — contention is uninteresting.

### T3 — `host-cpal`: RT control plane (`src/cpal/control.rs`)

Lives inside `host-cpal` because the only producer is the cpal
callback. If a second audio back-end (JACK, CoreAudio) later needs
the same plumbing, we promote this module to a shared crate —
until then, YAGNI.

```rust
#[derive(Copy, Clone, Debug)]
pub struct MidiMessage {
    pub at_sample: u64,
    pub bytes: [u8; 3],
    pub bytes_len: u8,   // valid prefix (1 for clock / transport;
                         // 3 reserved for Plan 14's MidiCc)
}

pub fn spsc(capacity: usize) -> (RtProducer, ControlConsumer);

pub struct RtProducer {
    inner: rtrb::Producer<MidiMessage>,
    dropped: std::sync::Arc<std::sync::atomic::AtomicU64>,
}

impl RtProducer {
    /// Non-blocking; returns `false` on full ring. Audio-thread
    /// contract: never allocates, never blocks.
    pub fn try_push(&mut self, msg: MidiMessage) -> bool;
    pub fn dropped_count(&self) -> u64;
}

/// `RtProducer` implements `MidiSink` by enqueueing to the ring, so
/// Plan 12's `render_channel_block(&dyn MidiSink, …)` drops in at
/// the callback call site with no renderer change. `bytes_len: 1`
/// covers the whole v0.1 surface (0xF8 + 0xFA/0xFB/0xFC); the 3-byte
/// array leaves room for Plan 14's `MidiCc`. On overrun, `dropped`
/// increments — policy pinned below.
impl agogo_core::out::midi::MidiSink for RtProducer { /* try_push */ }

pub struct ControlConsumer {
    inner: rtrb::Consumer<MidiMessage>,
}

impl ControlConsumer {
    /// Spawn a drain thread that forwards every message to `sink`.
    /// Returns a handle whose `Drop` signals the thread to flush +
    /// exit.
    pub fn spawn_drain(
        self,
        sink: std::sync::Arc<dyn agogo_core::out::midi::MidiSink>,
    ) -> DrainHandle;
}

pub struct DrainHandle { /* join + shutdown signal */ }
impl Drop for DrainHandle { /* signal + join */ }
```

**Overrun policy: drop newest on full.** Blocking the producer would
stall the audio thread — never. Plan 13 exports `dropped_count()`
so the demo CLI can warn if it ever increments. Ring capacity
default 1024 `MidiMessage` (≈ 16 KiB) — at 48 kHz / PPQN 192 /
120 BPM / divider T4 the producer emits ~2 msg/s; the drain thread
processes in under a ms. 1024 is ~orders of magnitude of headroom.

### T4 — `host-cpal`: callback hot loop (`src/cpal/callback.rs`)

```rust
/// State owned by the audio thread. Built on the control thread,
/// moved into the cpal callback closure, never re-touched by the
/// control thread thereafter.
pub struct CallbackState<R: SampleTime> {
    pub phase_source: agogo_core::sync::PhaseSource<R>,
    pub channel: agogo_core::channel::Channel,    // single-channel demo
    pub stc: agogo_core::time::conn::SampleTickConn,
    pub producer: crate::cpal::control::RtProducer,
    pub events: Vec<agogo_core::channel::ScheduledEvent>,  // preallocated
}

impl<R: SampleTime> CallbackState<R> {
    /// Entry point the cpal callback calls each buffer. No allocation,
    /// no locks.
    pub fn on_buffer(&mut self, io: &mut agogo_core::host::AudioIo) {
        // 1. Feed the PhaseSource (Internal: no-op; External: drive PLL).
        self.phase_source.feed_samples(io.input, io.buffer_start_sample);

        // 2. Schedule ticks for this buffer into the preallocated buf.
        self.events.clear();
        agogo_core::channel::scheduler::tick_stream_into(
            &mut self.events,
            &self.channel,
            &self.stc,
            io.buffer_start_sample,
            io.frames,
        );

        // 3. Render to the SPSC via the RtProducer's MidiSink impl.
        //    Plan 13 passes `transport: None`; caller-driven
        //    transport arrives in Plan 14's Playhead.
        agogo_core::out::midi::render_channel_block(
            &self.channel,
            &self.events,
            None,
            io.buffer_start_sample,
            &self.producer,
        );
    }
}
```

The pool size for `events` is computed at setup: at the chosen
`(sr, bpm, ppqn, divider, buffer_frames)`, `max_events_per_buffer`
is bounded by `buffer_frames * stc.ticks_per_sample_ceil() /
divider.tick_count()` + slack for swing displacement. T4's setup
helper exposes a public `max_events_for(cfg) -> usize` that the CLI
feeds into `Vec::with_capacity`.

**Rate dispatch.** `CallbackState<R>` is generic; the CLI
instantiates either `CallbackState<S44>` or `CallbackState<S48>`
based on `--sr` and moves the monomorphised closure into
`CpalHost::run`. Wider rate support is a matter of adding
`SampleTime` impls — no runtime dispatch.

### T5 — `agogo demo` CLI subcommand

File: `crates/cli/src/main.rs`.

Feature-gated behind `--features demo` (= `cpal` + `midir`). New
subcommand:

```
agogo demo
    --audio-in <device>           # cpal input (or "default")
    --midi-out <port>             # midir port (or "default")
    --source <internal|external>  # PhaseSource variant
    --bpm <f64>                   # argv → Tempo via F64TMP
    --sr <u32>                    # 44100 or 48000 for v0.1
    --divider <tbase>             # t4/t8/t16/t24/…
    --buffer-frames <u32>         # default 1024
    [--duration-ms <u32>]         # default 5000; fixed-duration run
                                   # (Plan 13 has no Ctrl-C handler;
                                   # `agogo run` in Plan 14 adds one)
    [--log-dropped]               # warns every 500 ms and exits 1
                                   # if `dropped_count > 0` at end
```

Two companion device-discovery subcommands:

```
agogo demo list-audio-inputs      # prints cpal device names
agogo demo list-midi-outputs      # prints midir port names
```

Handler flow:
1. Parse + validate argv; wrap every f64 at the boundary via the
   existing post-hardening `F64TMP` / `F64F06` conns.
2. `let sink = std::sync::Arc::new(MidirSink::open(port)?);`
3. `let (producer, consumer) = host_cpal::cpal::control::spsc(1024);`
4. `let drain = consumer.spawn_drain(sink);`
5. Build `CallbackState<S48>` (or `<S44>`) with the `producer`.
6. `CpalHost::default_input()?.run(cfg, Box::new(move |io| cb_state.on_buffer(io)))?`
7. Main thread sleeps for `duration_ms` ms. (No Ctrl-C handler in
   Plan 13; SIGINT hard-kills the process before the teardown
   steps below. `agogo run` in Plan 14 adds signal handling.)
8. Drop the audio `Handle` (pauses the stream). Drop `drain` (joins
   the drain thread). Exit.

### T6 — Integration tests

Files:
- `crates/host-cpal/tests/` (new):
  - `spsc.rs` — pure-logic SPSC tests.
  - `callback.rs` — callback-driven end-to-end against `TestSink`.
  - `cpal_hardware.rs` — fixture-gated real-device smoke.
- `crates/host-midi/tests/`:
  - `midir_hardware.rs` — fixture-gated real-port loopback.

Pure-logic tests (no system devices required):

- **`spsc_round_trip`** (proptest) — arbitrary `Vec<MidiMessage>` up
  to ring capacity yields the same sequence on the consumer side in
  FIFO order. Overflow bumps `dropped` exactly by the excess.
- **`callback_renders_to_testsink`** — substitute the MIDI sink with
  `TestSink` (from Plan 12) directly, skipping the SPSC, drive
  `CallbackState::on_buffer` with synthetic `AudioIo` slices (silence
  for `Internal`; hand-generated pulse train for `External`), assert
  `TestSink` captures `0xF8` bytes at expected sample indices over N
  buffers.
- **`callback_allocation_free`** — fixture-gated `"alloc_tracker"`
  (some CI environments can't swap the global allocator). Uses a
  tracking wrapper around `System`, scopes alloc counting to the
  `on_buffer` call, asserts zero heap allocations over 1000
  randomised buffers.

Hardware-fixture tests:

- **`cpal_default_input_smoke`** — fixture-gated
  `"cpal_default_input"`. Opens the default input, captures 100 ms,
  asserts at least one non-zero sample. Validates cpal wires up.
- **`midir_loopback_roundtrip`** — fixture-gated
  `"midir_loopback"`. Opens a paired loopback port (e.g. IAC bus on
  macOS, loopMIDI on Windows, virmidi on Linux), sends ten `0xF8`
  bytes, asserts ten received on the reader side.

All hardware fixtures skip cleanly when the expected environment is
absent, per the existing `fixture_or_skip!` pattern.

### Design deviations from the plan

1. **`spawn_drain` takes `Arc<dyn MidiSink + Send + Sync>`, not
   `Arc<dyn MidiSink>`.** Plan 12's trait declared `MidiSink:
   Send` only; for `Arc<dyn MidiSink>` to be `Send` (movable into
   the drain thread), the trait object needs `Send + Sync`.
   Production back-end sinks (`MidirSink`) all satisfy this via
   their `Mutex`-wrapped state, so it's a non-breaking tightening
   at the API surface.

2. **`RtProducer: MidiSink` uses `RefCell` interior mutability.**
   `MidiSink::send_at(&self)` clashes with `rtrb::Producer::push
   (&mut self)`. `RefCell` makes this sound (single-thread borrow)
   since rtrb is SPSC by design — `RtProducer` is `Send` but
   `!Sync`, exactly the audio-thread ownership contract.

3. **`AudioIo::new` constructor** added in T0a. `#[non_exhaustive]`
   on `AudioIo` (forward-compat for v0.5's Link timestamp per
   `link.md:23-29`) prevents external struct-literal construction;
   the constructor lets `host-cpal` build it from outside
   `agogo-core`. When v0.5 adds a field, the constructor's
   signature breaks intentionally — every back-end has to
   acknowledge the new field.

4. **`max_events_for_buffer(frames)` simpler than plan.** Plan
   specified a divider-aware bound. Simpler `frames + 16` is the
   absolute ceiling (one event per sample, +slack for swing
   displacement) regardless of `(bpm, divider)`.

5. **`agogo demo` subcommand structure: explicit verbs.** Plan's
   `agogo demo --bpm ...` (no verb) conflicted with `agogo demo
   list-audio-inputs` (verb). Restructured as `agogo demo run
   --bpm ...` + `agogo demo list-*`. Cleaner under bpaf.

6. **Plan 13 T5 supports `--sr 48000` only.** Wider rate dispatch
   via static `match args.sr { 44_100 => CallbackState::<S44>,
   48_000 => CallbackState::<S48>, ... }` lands with `agogo run`
   in Plan 14, where the v0.1 acceptance scenario pins the
   supported set. `agogo demo` errors cleanly on other rates.

7. **No Ctrl-C handling in `agogo demo`.** The demo runs for
   `--duration-ms` and exits. Signal handling (via `signal-hook`
   or equivalent) lands with `agogo run` in Plan 14.

8. **`--log-dropped` flag dropped from T5.** Plan listed it as a
   periodic-warn flag that exits 1 if `dropped_count > 0` at end.
   The exit-1-on-drop semantics already ship implicitly (the
   handler's final `if dropped > 0 { return Err(...) }` exits 2);
   the periodic-warn surface adds a polling thread that's
   noise-only for the demo's typical 5 s runs. Land the periodic
   variant with v0.4 telemetry (`tui.md` audio-load gauge) where
   it has actual peer signals to display next to.
