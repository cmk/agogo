# Plan 2026-05-02-09 - Forbid hand-built unlawful connections

## Goal

Stop agogo from constructing ad-hoc `Conn` / `ConnL` / `ConnR`
values directly, audit every existing connection-shaped conversion for
domain lies, and make the project rules explicit: intentionally writing
an unlawful connection and hiding the failure by constraining the
proptest generator is forbidden. If a lawful connection is not obvious,
the correct action is to stop and ask for the missing math or API
shape, not to fake totality with an `expect`.

This sprint exists because `TICKTIME` currently exposes a
`Tick -> Time` connection over the full `Tick(u64)` type while finite
`Time::At { beats: u32, base }` cannot represent every tick. The
implementation documents a precondition and unwraps with `expect`,
while `arb_tick` avoids the failing part of the domain. That is not a
lawful total connection over the declared types.

## Context Read

  `Conn::new_l` / `Conn::new_r` directly instead of using upstream
  declaration macros.
- `crates/core/src/time/conn.rs::TICKTIME` used to panic outside a
  bounded tick horizon while its proptest generator stayed below that
  horizon.
- `crates/core/src/time/conn.rs::TIMETIME` and `quantize_at` also

  `doc/audits/{README,coverage,docrot,hygiene,pii,proptest}.md`,

- The local `../connections` checkout is currently
  `3a0f8f23f5c8c789597d23ef3ced30bda16afce4`, which contains the
  exported `compose_l!`, `compose_r!`, `compose!`, `triple!`, and

## Tasks

### T1 - Copy audit harness + bump connections

Problem or motivation: agogo needs recurring mechanical audits for the
same generator-cooking failure mode that already occurred here and
upstream. The harness already exists in `../connections` and should be
ported rather than rewritten. The upstream version invokes
`claude -p`; agogo's port should use `codex exec -`.

Solution / implementation approach: Copy the eight files added by
`../connections` commit `238a8aaf913db48a31c1d7409504fb9c2745d3cd`
into agogo, adjusting prompts only where paths, branch names, or command
names differ. Replace Claude invocation with non-interactive Codex
invocation, pass prompts over stdin, and fail loudly on any execution
problem: missing `codex`, nonzero Codex exit, invalid audit front matter,
`audit_state.sh` failure, or empty Codex output. Mark the audit pin only
after a successful invocation. Bump the workspace `connections`
dependency to the newest usable hash with the exported connection
declaration/composition macros (expected local target:
`3a0f8f23f5c8c789597d23ef3ced30bda16afce4`, unless a newer upstream
hash is available during implementation).

Types / API surface: No Rust API changes in this task. New files live
under `doc/audits/` and `scripts/`. `scripts/audit_state.sh since-last`
and `last` should be read-only when no pin exists; only `mark` creates
`.git/audit-state/`.

### T2 - Add a constructor gate

Problem or motivation: Direct calls to `Conn::new_l`, `Conn::new_r`,
or local wrappers let agogo publish a value with the shape of a
connection without passing through the upstream macros that make the
constructor intent reviewable.

Solution / implementation approach: Add `scripts/check-connections.sh`
and wire it into `.githooks/pre-commit`. The check should reject
production-code construction sites for:

- `Conn::new_l`
- `Conn::new_r`
- local marker-construction macros such as `def_conn_marker!`
- local runtime triple builders such as `RuntimeConn::new`

Allowed construction forms in agogo production code are the exported
upstream macros: `connections::triple!`, `connections::iso!`,
`connections::compose!`, `connections::compose_l!`, and
`connections::compose_r!`. If direct constructor calls are unavoidable
inside tests, fixtures, or a temporary migration shim, they must be
explicitly allowlisted with a narrow comment and a Review entry in this
plan.

Types / API surface: Shell gate only. The script should be runnable
directly and from the pre-commit hook.

### T3 - Migrate obvious lawful conns to upstream macros

Problem or motivation: Some local connection definitions probably are
lawful and merely use the wrong construction mechanism.

Solution / implementation approach: Replace local marker helpers in
`crates/core/src/conn/{fixed,float,sample}.rs` and any clean static
connections in `crates/core/src/time/conn.rs` with upstream macros.
Keep helper functions for `ceil` / `inner` / `floor` when those bodies
are already clear and total, but let the public marker declaration come
from `triple!`, `iso!`, or `compose!`.

Types / API surface: Preserve existing public names where lawful.
Changing a value from a local marker to an upstream macro marker is OK
only if `.ceil()`, `.inner()`, `.floor()`, `ViewL`, and `ViewR` call
sites keep working or receive a small mechanical update.

### T4 - Audit and fix or stop on buggy connections

Problem or motivation: The important bug is not direct constructor use
by itself; it is using that freedom to lie about domains.

Solution / implementation approach: Audit every connection-shaped item
and every proptest generator that feeds it. For each candidate, answer:

- Is every public method total over the declared Rust input type?
- Does any `ceil` / `floor` / `inner` use `expect`, `unwrap`, `panic`,
  `unreachable`, arithmetic overflow, or a documented precondition?
- Does the generator use a bounded domain to avoid panic, wrap,
  saturation, or representability failure?
- Does the type encode the actual domain, or is the true domain a
  subset hidden in prose?

Fixes must use one of these shapes:

- a genuinely total upstream-macro connection over the declared types;
- a narrower domain type such as `BoundedTick` / `RepresentableTick`;
- an extended codomain that can represent top/bottom/failure lawfully;
- deleting or demoting the API when no lawful connection exists.

If the correct shape is not clear, stop before writing the conversion
and work with the user. Do not land a partial law by bounding the
generator.

Known first audit targets:

- `TICKTIME`: replace `Tick(u64) -> Time` with a top-completed
  codomain so overflow remains explicit.
- `quantize_at`: demote from connection-shaped API to a total
  fixed-grid `Tick -> Time` rounder.
- `TIMETIME`: use `Time::End` as refinement top and finite zero as
  the existing refinement bottom for LCM overflow / finite-horizon
  misses.
- `SampleTickConn`: conn-shaped runtime conversion, not a real
  upstream `Conn`; verify totality and whether its type name/comment
  remain acceptable under the new rule.
- agogo-local fixed/float/sample macros that directly construct
  `ConnL` / `ConnR`.

Types / API surface: TBD per audited item. Any public API narrowing or
extended codomain must be reviewed with the user before implementation.

### T5 - AGENTS rule + audit prompts

Problem or motivation: The repo instructions currently warn against
bounded proptest generators, but they do not say plainly enough that
publishing an unlawful connection and hiding it with generator bounds is
professional misconduct for this codebase.

Solution / implementation approach: Update `AGENTS.md` with a dedicated
connection-construction rule:

- Do not construct agogo connections directly with `Conn::new_l`,
  `Conn::new_r`, or local wrappers.
- Do not add `expect` / `unwrap` / preconditions inside connection
  adjoints to force totality.
- Do not bound generators to keep unlawful adjoints from seeing their
  failing domain.
- If a lawful construction is not known, stop and ask. It is
  categorically better to say "I do not know how to implement this
  connection lawfully" than to fake it.

Add or adapt the upstream `doc/audits/proptest.md` prompt so the
recurring audit specifically searches for connection-domain lies and
generator cooking.

Types / API surface: Documentation and audit prompt changes only.

### T6 - Verification

Problem or motivation: A gate that misses one local constructor or a
generator that still dodges a panic recreates the failure pattern.

Solution / implementation approach: Add script tests / spot checks for
the constructor gate and Rust tests or proptests for every migrated or
repaired connection.
