# Plan 2026-05-04-05 - Audio/CV offline render identity property

## Goal

Add the deterministic offline-demo property discussed in `doc/notes/prop-tests.md`
without waiting for a future polarity path: generate a wide audio/CV channel spec,
lower it twice, drive the real offline render path twice, and assert exact
sample/report equality.

This is intentionally an identity property, not cancellation. The repo still has
mono output and no signed per-channel polarity control, so cancellation would
either require test-only machinery or accidentally test clipping details instead
of the channel pipeline.

## Tasks

### T1 - Add an audio/CV `ChannelSpec` strategy

Define a transport-local strategy that builds valid `ChannelSpec` values for
`dev=audio,mode=click` and `dev=cv,mode=pulse`.

The strategy must cover:

- the full `Grid::ALL` strategy via `arb_grid`;
- the existing `arb_swing` strategy;
- audio and CV roles;
- `delay`, `offset`, and `bars` with boundary-biased values.

Because this property drives real offline buffers, keep the duration and buffer
sizes bounded for test runtime. Document those runtime bounds directly above the
strategy or property.

### T2 - Assert offline render identity over generated specs

For each generated spec, lower it into two fresh `Channel`s and call
`render_offline` twice with the same tempo, sample rate, buffer size, and total
frame count. Assert the complete `OfflineRenderReport` values are equal.

The property should drive several consecutive buffers so it exercises per-channel
counter state, bar multipliers, CV pulse reset state, and buffer boundary
crossings.

## Review

- `FD12FD06` - full-domain `Micro(i64::MIN)` offset generation originally
  overflowed during the FD06->FD12 integer Conn
  before transport scheduling could handle it. Local review correctly flagged
  that saturating inside the Conn breaks fixed-ladder round-trip laws. Fixed in
  this sprint by keeping `inner` exact and clamping extreme `Micro` values at
  the `micro_to_samples` runtime boundary before the FD06->FD12 Conn call.
