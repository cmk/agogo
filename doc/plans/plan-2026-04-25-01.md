# Plan 16 — Polyrhythm DSL Parser

## Context

The Grid lattice (36 elements, bi-Heyting algebra) and SwingConfig are
fully implemented and proptested. The Heyting implication and pseudo-
complement exist in `grid.rs`; co-Heyting coimplication and co-negation
do not yet. The DSL is the user-facing syntax that maps to these types
— a thin parser over math that already exists. Parsing
`T16~T16:80@-50` should produce a `TrackSpec` that the caller wires
into the existing `Channel` pipeline. Polyrhythm is achieved by
specifying multiple `--ch` flags (one per channel).

## Goal

1. Extend `grid.rs` with co-Heyting algebra ops (`coimp`, `coneg`) and
   rename the Heyting ops for consistency (`heyting` → `imply`).
2. Ship a hand-written recursive descent parser for the polyrhythm DSL,
   producing `TrackSpec` from a string.
3. Zero new dependencies. Full proptest coverage including round-trip
   and fuzz.

## Grammar

```
track      := expr modifier*
expr       := impl_expr
impl_expr  := join_expr ( ('>' | '<') join_expr )*    # imply / coimp
join_expr  := meet_expr ( '|' meet_expr )*            # join / LCM
meet_expr  := unary ( '&' unary )*                    # meet / GCD
unary      := '!' unary | primary                     # negation (prefix)
primary    := atom | '(' expr ')'
atom       := 'T' <n>                                 # binary grid
            | 'T' <n> 't'                             # triplet
            | 'T' <n> 'q'                             # quintuplet
            | 'T' <n> 'p'                             # 15-tuplet
modifier   := '~' <TBase> ':' <i8>                    # swing (resolution : amount)
            | '@' <ticks>                             # musical offset (signed i32)
```

The DSL produces a single `TrackSpec` per expression. Polyrhythm is
achieved by specifying multiple `--ch` flags, one per channel.

### Operator table

| Symbol | Operation | Lattice / set semantics | Precedence |
|--------|-----------|------------------------|------------|
| `!`    | neg (pseudo-complement) | Heyting ¬a = a → ⊥ | tightest (prefix) |
| `&`    | meet (GCD) | common refinement | tightest binary |
| `\|`   | join (LCM) | alignment intersection | middle |
| `>`    | imply (Heyting →) | max{c : a ∧ c ⊑ b} | below join |
| `<`    | coimp (co-Heyting \\) | min{c : a ⊑ b ∨ c} | below join (same as >) |

All binary operators are left-associative.

### Precedence (tightest to loosest)

```
1. !          prefix negation (pseudo-complement)
2. &          meet / GCD
3. |          join / LCM
4. >  <       implication / coimplication
```

### Examples

```
T16~T16:80                     # 16ths with T16-resolution swing, amount +80
T4 & T2q                       # 4-against-5: quarters vs quintuplet halves
T16t & T16q                    # 24-vs-40 polyrhythm
T8 | T8t                       # alignment intersection of 8ths and triplet 8ths (= T4)
T16 ^ T16t                     # common refinement of 16ths and triplet 16ths (= T32T)
T16~T16:80 & T8t@-50           # swung 16ths against triplet 8ths offset -50 ticks
T8 & (T16t ^ T16q)             # 8ths ∥ 15-tuplet refinement of triplet+quintuplet 16ths
!T16                           # pseudo-complement of T16 grid
T16 > T8                       # Heyting implication: largest c with meet(T16, c) ⊑ T8
T16 < T8                       # co-Heyting coimplication: smallest c with T16 ⊑ join(T8, c)
```

### Trait naming convention

| Heyting | Coheyting |
|---------|-----------|
| `imp` (primitive) | `coimp` (primitive, was `sub`) |
| `neg` (derived: `self.imp(&Self::bot())`) | `coneg` (derived: `Self::top().coimp(self)`) |
| `mid` (derived: `self.join(&self.neg())`) | `comid` (derived: `self.meet(&self.coneg())`) |

### Trait changes in `connections/src/lattice.rs`

```rust
pub trait Heyting: Join + Meet {
    /// Heyting implication: max{c : a ∧ c ⊑ b}
    fn imp(&self, other: &Self) -> Self;

    /// Heyting negation (pseudo-complement): a → ⊥
    fn neg(&self) -> Self { self.imp(&Self::bot()) }

    /// Heyting middle: a ∨ ¬a (not necessarily ⊤)
    fn mid(&self) -> Self { self.join(&self.neg()) }
}

pub trait Coheyting: Join + Meet {
    /// Co-Heyting coimplication (subtraction): min{c : a ⊑ b ∨ c}
    fn coimp(&self, other: &Self) -> Self;

    /// Co-Heyting co-negation: ⊤ \ a
    fn coneg(&self) -> Self { Self::top().coimp(self) }

    /// Co-Heyting co-middle (boundary): a ∧ ~a
    fn comid(&self) -> Self { self.meet(&self.coneg()) }
}
```

Rename `Coheyting::sub` → `Coheyting::coimp`. `Symmetric::not` stays.

The `coimp` body (brute-force over 36 elements):
```rust
fn coimp(&self, other: &Self) -> Self {
    Grid::ALL.iter().copied()
        .filter(|c| self.ple(&other.join(c)))
        .reduce(|a, b| a.meet(&b))
        .expect("T1 always satisfies self ⊑ other.join(&T1)")
}
```

Note: `neg` (Heyting) ≠ `coneg` (co-Heyting). On this lattice:
- `meet(x, neg(x)) = ⊥` for all x (law of non-contradiction)
- `join(x, coneg(x)) = ⊤` for all x (law of excluded middle)
- But `neg(x) ≠ coneg(x)` in general (not Boolean)

### AST types

```rust
pub struct Span { pub start: usize, pub end: usize }

pub enum Expr {
    Atom(Grid, Span),
    Neg(Box<Expr>, Span),                // !
    Meet(Box<Expr>, Box<Expr>, Span),    // &
    Join(Box<Expr>, Box<Expr>, Span),    // |
    Imply(Box<Expr>, Box<Expr>, Span),   // >
    Coimply(Box<Expr>, Box<Expr>, Span), // <
}

pub enum Modifier {
    Swing(TBase, i8, Span),     // ~T16:80
    Offset(i32, Span),          // @-5
}

pub struct TrackAst {
    pub expr: Expr,
    pub modifiers: Vec<Modifier>,
    pub span: Span,
}

```

An intermediate AST is warranted because:
- Round-trip proptest (`Display → parse → compare`) needs the syntactic
  structure (which operators were used), not just the evaluated Grid
- Error messages need span context from the AST
- Parser correctness is testable independently of evaluation

### Error type

`DslError { kind: DslErrorKind, span: Span, source: String }` with a
`Display` impl that shows the source and a caret under the error span.

Variants: `EmptyInput`, `UnexpectedChar`, `UnexpectedEof`, `Expected`,
`InvalidAtom`, `InvalidSwingResolution`, `SwingAmountOutOfRange`,
`DuplicateModifier`, `OffsetOutOfRange`,
`UnmatchedParen`, `NestingTooDeep`.

### Lexer tokens

`Atom(String)`, `Ampersand`, `Pipe`, `Gt`, `Lt`, `Bang`,
`Tilde`, `At`, `Colon`, `Int(i64)`, `LParen`, `RParen`.
When `-` immediately precedes digits (no space), lexer emits `Int(-N)`.

### Display (precedence-aware)

`Expr::fmt_with_prec(parent_prec)` emits `()` when a lower-precedence
node appears as a child of a higher-precedence node.
Precedence levels: Atom = 4, Neg = 3, Meet = 2, Join = 1, Imply/Coimply = 0.
Right children use `parent_prec + 1` for left-associativity.

### Parser structure (recursive descent)

```
parse_track     → parse_expr modifier*
parse_expr      → parse_impl_expr
parse_impl_expr → parse_join_expr (('>' | '<') parse_join_expr)*  // prec 0
parse_join_expr → parse_meet_expr ('|' parse_meet_expr)*          // prec 1
parse_meet_expr → parse_unary ('&' parse_unary)*                  // prec 2
parse_unary     → '!' parse_unary | parse_primary                 // prec 3
parse_primary   → atom | '(' parse_expr ')'                       // prec 4
```

Max nesting depth of 32 (enforced in `parse_unary` and `parse_primary`).

#### Heyting properties (h0–h17)

Generic signatures like `fn heyting_adjunction<T: Heyting>(x: &T, y: &T, z: &T) -> bool`.

| # | Name | Law |
|---|------|-----|
| h0 | adjunction | `x.meet(y) ⊑ z ⟺ x ⊑ y.imp(z)` |
| h1 | imp monotone (join 2nd) | `x.imp(y) ⊑ x.imp(y.join(z))` |
| h2 | imp antitone (join 1st) | `x.join(z).imp(y) ⊑ x.imp(y)` |
| h3 | imp monotone (ple 2nd) | `x ⊑ y ⟹ z.imp(x) ⊑ z.imp(y)` |

| h6 | weakening | `y ⊑ x.imp(x.meet(y))` |
| h7 | modus ponens | `x.meet(x.imp(y)) == x.meet(y)` |
| h8 | neg boundary | `bot.neg() == top ∧ top.neg() == bot` |
| h9 | neg-join ≤ imp | `x.neg().join(y) ⊑ x.imp(y)` |
| h10 | imp = top iff ple | `x ⊑ y ⟺ x.imp(y) == top` |
| h11 | neg antitone (join) | `x.join(y).neg() ⊑ x.neg()` |
| h12 | neg-imp de Morgan | `x.imp(y).neg() == x.neg().neg().meet(y.neg())` |

| h14 | non-contradiction | `x.meet(x.neg()) == bot` |
| h15 | triple neg | `x.neg().neg().neg() == x.neg()` |

### Edge cases

| Case | Expected |
|------|----------|
| Empty / whitespace-only input | `Err(EmptyInput)` |
| Whitespace between tokens | Ignored: `"T16 ^ T8"` is valid |
| Whitespace within atom | Error: `"T 16"` fails |
| Duplicate modifiers | `Err(DuplicateModifier)` |
| Swing amount > i8 | `Err(SwingAmountOutOfRange)` |
| Offset > i32 | `Err(OffsetOutOfRange)` |
| Unmatched parens | `Err(UnmatchedParen)` |
| Trailing garbage | `Err(Expected)` |
| Adjacent operators `T16&^T8` | Error at second `^` |
| Empty parens `()` | Error: expected expression |
| Nesting depth > 32 | `Err(NestingTooDeep)` |
| Case insensitivity | `"T16Q"` and `"t16q"` both valid |
| `!` without operand | `Err(Expected)` |
| Chained `>` `<` without parens | Left-assoc: `a > b < c` = `(a > b) < c` |
