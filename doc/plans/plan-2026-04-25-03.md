# Plan 18 — Bump connections + Grid lattice trait impls

## Context

The `connections` crate (MR !8) now exports `Join`, `Meet`, `Heyting`,
`Coheyting` traits with provided methods (`neg`, `mid`, `coneg`,
`comid`). Grid's lattice operations are currently standalone functions
in `grid.rs`. This sprint bumps the dependency and migrates Grid to
trait implementations, removing the standalone functions and updating
all call sites to method syntax.

## Goal

1. Bump `connections` rev to `d1ac1ea`.
2. Implement `PartialOrd`, `Join`, `Meet`, `Heyting`, `Coheyting`
   for `Grid`.
3. Remove standalone functions (`meet`, `join`, `imply`, `neg`, `mid`,
   `coimp`, `coneg`, `comid`).
4. Update all call sites to trait method syntax.

## Tasks

### T1 — Bump rev + implement traits

In `Cargo.toml`: bump `connections` rev to `d1ac1ea`.

In `crates/core/src/time/grid.rs`:
- Add `PartialOrd` impl based on `Ple` (divisibility preorder)
- `impl Join for Grid` — `bot() = T512P`, `join` = min on n + && on bools
- `impl Meet for Grid` — `top() = T1`, `meet` = max on n + || on bools
- `impl Heyting for Grid` — `imp` = brute-force witness over ALL
- `impl Coheyting for Grid` — `coimp` = brute-force witness over ALL
- `neg`, `mid`, `coneg`, `comid` come from trait provided defaults
- Remove all standalone `pub fn` functions

### T2 — Update call sites

Every `grid::meet(a, b)` → `a.meet(&b)`, etc. Files:
- `dsl/eval.rs` — evaluator core + tests
- `dsl.rs` — integration tests
- `time/conn.rs` — grid pair ceil/floor + tests
- `time/grid.rs` — internal tests

Remove `use crate::time::grid::{self, Grid}` → `use crate::time::grid::Grid`
and add `use connections::lattice::{...}` where trait methods are called.
