## Tasks

### T1 — Bump `connections`

**Problem.** `agogo` is pinned to `connections` rev
`01a2bf92cbe3d3e7eda7ab91f5b4dfc9cc6f4242`, but the local checkout is
at `238a8aaf913db48a31c1d7409504fb9c2745d3cd`.

**Solution.** Update the workspace `connections` git rev and refresh
`Cargo.lock`. Keep this as a git dependency, not a local path patch.

### T2 — Migrate local `Conn` definitions

**Problem.** Current `connections` HEAD uses kind-tagged `ConnL` /
`ConnR` plus `ViewL` / `ViewR`; agogo still constructs several
three-function `Conn::new(...)` values and two one-sided MIDI Conns
with the old constructor names.

**Solution.** Convert true triples to zero-sized marker structs that
implement both views and keep narrow inherent forwarders for existing
call sites. Convert one-sided MIDI connections to `ConnL` values built
with `Conn::new_l`.

### T3 — Replace matching ad hoc casts

**Problem.** A handful of integer casts manually clamp or saturate in
ways already represented by upstream integer Conns.

**Solution.** Replace matching sites with named upstream Conns:

- `i64 -> u64`: `connections::fixed::u64::I064U064.ceil`
- `i128 -> u64`: `connections::fixed::u64::I128U064.ceil`
- `u128 -> u64`: `connections::fixed::u64::U128U064.ceil`
- `u64 -> i64`: `connections::fixed::i64::U064I064.floor`
- `u128 -> u8`: `connections::fixed::u8::U128U008.ceil`

Leave torus wrapping (`Phase`), Link/PI/PCM ABI float seams, and
round-to-nearest FFI parity helpers unchanged unless a Conn composition
preserves their documented rounding exactly.

### T4 — Verification and docs

**Problem.** Constructor migration and cast replacement can compile
while subtly changing rounding or saturation behavior.

**Solution.** Keep or add properties that assert each migrated Conn's
lawful behavior and each replaced cast's boundary behavior. Update
comments that name old constructor or one-sided-triple semantics.
