# Plan 2026-04-29-01 — Reorganize crates/core into five top-level modules

## Goal

Collapse `crates/core/src`'s ad-hoc top-level layout
(`boundary`, `channel`, `dsl`, `host`, `machine`, `midi`, `out`,
`sync`, `testing`, `time`) into five intent-named layers — `conn`,
`time`, `channel`, `control`, `sink` — plus a `test` rename of
`testing`. Add a layering rule (partial-order import graph) and
enforce it in `.githooks/pre-commit` + CI.

## Context

The current top-level seams aren't load-bearing:

- `dsl` and `machine/spec` are both *channel configuration*.
- `host` and `out` are both *sinks*.
- `sync` and `machine` are both *control plane*.
- `boundary`, `midi`, parts of `time` (`decimal`, `sample`,
  `float`, `tempo`) and `sync/phase` are all *value-type seams
  between numeric realms*.

`doc/notes/mess.md` is the source roadmap. The payoff: each
module name says what it's for, the public API surface in
`lib.rs` shrinks to six items, and the "can-A-import-B?" question
gets a mechanical answer.

## Decisions (frozen before T0)

1. **Branch, not worktree** — no other Claude is active in this repo.
2. **`sample_tick.rs` merges into `time/conn.rs`.** The
   `SampleTickConn` joins the existing Galois conns over
   Tick/Time/Grid in `time/conn.rs`. `sync/sample_tick.rs` is
   deleted; no `control/sync/sample.rs` is created.
3. **`boundary.rs` lives at `conn/boundary.rs`.** To keep `conn`
   a layering leaf, `Phase` (Q0.32 torus quotient) and `Tempo`
   (`u32` µBPM wrapper) move into `conn/` alongside the other
   conn-shaped value types. The `test` module stays a clean
   test-utility namespace (just `fixture_or_skip`), not a
   quarantine.
4. **One mega-PR, eight atomic commits** on `plan/2026-04-29-01`.
5. **Sweep yesterday's plans + CLAUDE.md** for old path
   references as a final atomic commit (T8).

## Layering rule (enforced)

```
control  → sink, channel, time, conn
sink     → channel, time, conn
channel  → time, conn
time     → conn
conn     → (leaf)
test     → (leaf)
```

Each top-level module-root file declares its allowed upstream
deps in a sentinel header comment, e.g.

```rust
// in time.rs:
//! layer: time
//! depends-on: conn
```

`scripts/check-layers.sh` parses these headers, walks every
`use crate::<top>` (or `use agogo_core::<top>` in tests) under
each layer, and fails on any back-edge.
