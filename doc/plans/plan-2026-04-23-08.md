### T2 — Channel state flips to `Micro`

`crates/core/src/channel/transform.rs`:

```rust
use connections::conn::fixed::{Micro, F12F06};

pub const MAX_SHIFT: Micro = Micro(300_000);  // 300 ms

pub struct Channel {
    ...
    pub shift:  Micro,   // was shift_ms: f32
    pub offset: Micro,   // was offset_ms: f32
}
```

Compose `F12F06` (Pico↔Micro) with `PicoSampleConn` (T0 from plan-07)
at every use-site. Identical pattern in `channel/scheduler.rs`.

### T3 — CLI argv f64 via Conns

`crates/cli/src/main.rs` TraceArgs becomes `{ bpm: Tempo, shift: Micro,
offset: Micro }`. bpaf keeps accepting f64 from the terminal; handler
wraps once at the parser boundary via `F64F06.ceil` / `f64_bpm_to_tempo`
per CLAUDE.md's argv-boundary rule.

### T4 — `ProbeRow` stops holding floats

Keep `tempo: Tempo` and `phase: Phase` in `ProbeRow`; inline the
display-time `phase_u32 / 2^32 as f64` at `println!` time.

### T5 — `LinkClock` surface exposes `Tempo`

`crates/host-link/src/link.rs`:

```rust
impl LinkClock {
    pub fn new(initial_bpm: Tempo, anchor: HostTimeAnchor) -> Self;
    pub fn tempo(&mut self) -> Tempo;
}
```

The f64 ↔ Link FFI is genuine ABI; contain it in two
`// Link FFI`-annotated sites inside the impl.

### T7 — `scripts/check-floats.sh` grep gate + CI wire

New `scripts/check-floats.sh`. Passes only if every `f32` / `f64` hit
in `crates/*/src/` has one of these annotations within 2 lines:
`// PI-exempt`, `// ABI-local`, `// PCM ABI`, `// argv boundary`,
`// Link FFI`. Wire to `.github/workflows/ci.yml` as a job. Any
un-annotated hit is a CI failure.

### T8 — CLAUDE.md + review-calibration.md rule additions

- **Every numerical conversion comes from a named `Conn`** rule.
- **Cross-conversions compose existing `Conn`s** rule with concrete
  good/bad examples.

Append Patterns 9/10/11 to `doc/reviews/review-calibration.md` —
